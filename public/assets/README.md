# 游戏运行资源

`imba/` 包含默认游戏的地图数据、寻路、模型、贴图和音效；`original/` 为独立模型查看器资源；`presentation/` 为加载界面图片。本 GitHub 快照包含这些运行资源。

来源和 SHA-256 记录见 `../../artifacts/imba/asset-manifest.json` 与 `../../artifacts/imba-playable/assets.json`。运行 `npm run map:check`、`npm run play:check` 验证完整性。

原始 W3X 文件未随仓库提供。第三方资源的权利归各自权利人所有，详见根目录 README。
